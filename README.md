# 中考人生模拟器 · 红塔中学版

玉溪市红塔中学（玉溪一中附属中学）社团开发项目。
由学校社团学生自主开发，用于全校展示与教学实践。

一款「初中三年」主题的网页文字养成游戏。学生扮演一名红塔少年，
从初一走到中考。每周有有限的**剩余时间**，拿它去学习、做题、休息、
参加社团、出门走走；每次选择都会引出事件，最后汇总成中考成绩与结局。

校训「人生在立，行达天下」　|　登上「立行号」，每一步都算数

核心设计：天赋不是开局送的，是在一次次选择里长出来的；
负面天赋（厌学、网瘾、拖延症等）可以靠坚持行动「破茧」消除，
久不练习的正面天赋也会退化。

当前版本：**v1.4.3（性能优化版）** —— 更新日志见 `docs/changelog.md`。
开发者接手请先读 `docs/HANDOVER.md`（红线与踩坑）与 `content/README.md`（内容总入口）。

## 这一版有什么

- 一学期 20 周，三年共 120 周；**寒暑假不计入周数**，学期之间连续编号
- 中考三段结算：初二下生地会考锁分 → 实验操作 → 初三下中考，总分 530
- 语文 87 分以后越往上越难；物化生卷面 90 分 + 实验 10 分
- 一周改成**剩余时间池**：行动与事件选项都扣时间，付不起的按钮直接灰掉
- 做题可选科目、可选 1~5 道，题库 493 题，只抽本年级开设的科目
- 事件池：社团 104 条、随机日常 30 条、长链 5 条主线（最长 6 层分支收束）
- 真实模式下选项、飘字、反馈弹窗都不给具体数值；经济任何模式都给数字
- 周末时间表：带入上次安排、可清空 / 恢复、不能执行的标灰、逐段结算
- 文具袋与图书：笔会磨坏，书有阅读进度，借来的书到期会还回去
- 九套主题（含随季节变色的「四季」、随呼吸流动的「风」），卡片分层
- 假期旅游副本、节假日事件、亲情事件、每周结束自动存档
- 事事有回应：每次选择都有文本弹窗，解锁天赋与成就一起弹出来
- 内置五子棋与背景音乐（可导入本地音频、调音量）；主菜单有消息栏
- 创角独立一页：三档真实度、四档难度、六个学期都能开局、可自选天赋

## 时间与校历

| 项 | 规则 |
|---|---|
| 学期 | 6 个学期，每学期 20 周，全局周号 1~120 |
| 假期 | 寒假 / 暑假各一段，不占周号，顶栏显示「❄️ 寒假」而非「第 N 周」 |
| 时段 | 周中 → 周三社团课 → 周末，按序推进，不会倒流 |
| 月份 | 9 月开学 → 次年 1 月，2 月开学 → 6 月，春 🌸 夏 🌞 秋 🍂 冬 ❄️ |
| 社团 | 13 个社团，只在周三有课；每学年上学期第 3~5 周抢一次，可续留 |
| 固定日程 | 开学、月考、期中、期末、体艺节（少年 / 行者 / 星辰大海）、会考、实验考 |

每个寒暑假有专属事件集（每套 5 条主事件 + 7 条连锁）；国庆、元旦、
清明、劳动节占整周，中秋、端午、五四、教师节只弹一条事件。

## 核心机制

**八项属性**：心态、经济、健康、效率、悟性、社交、压力、亲情（0~150）。
可见性按真实度走：游戏模式全数值，模拟模式五档文字（**经济永远给数字**），
真实模式四项可见、除经济外模糊化。隐藏属性照常计算，只是不显示。

**剩余时间**：每周 replenish 一次，学习 / 运动 / 做题 / 读书 / 事件选项
各有定价。主动点「进入下一周」把没用完的时间按天赋折成健康。
游戏 / 模拟模式显示具体数值，真实模式只有条的长度。

**中考三段**（总分 530）：

| 段 | 时间 | 说明 |
|---|---|---|
| 生地会考 | 初二下期末 | 生物、地理考完锁死，初三不再学 |
| 实验操作 | 临近大考 | 生物 / 物理 / 化学各 10 分，第一次认真做就拿满 |
| 毕业中考 | 初三下期末 | 语数英 ×100%、物 ×50%、史政 ×40%、生 ×40%、地化 ×30% |

**天赋**：开局可按额度自选（游戏 6 点 / 模拟 4 点，家庭背景计入额度，
按 Lv 累加，互斥天赋按 `inc` 排斥表双向校验）。读书、事件、破茧也能获得天赋；
破茧消负面，退化掉久不练习的正面天赋。

**文具袋**：开局随机给一支笔、橡皮和一只袋。书写类文具是学习 / 做题 /
读书的硬门禁；文具会磨损报废，袋身归零会「散落」（效率下降、更容易丢东西）。
耐久在游戏 / 模拟模式给数值，真实模式只有条长。小卖铺按「笔 / 橡皮 / 文具袋 / 运动器材 / 尺具实验 / 小物 / 书」分组陈列全部文具与书，固定价；**只有笔和橡皮占文具袋格子**，
周末上网按周号确定性刷新 4 件（含 2 本书），价格有浮动。

**图书**是特殊文具，有进度条：耗时间推进，进度受效率、悟性、天赋影响，
不同书的「时间→进度」比例不同，分阶段给反馈，读完可抽一个正面天赋
（家庭背景类排除）。借来的书有时限，借出的书到期会回来。

**手机**：学校对手机零容忍。自习课玩、宿舍藏手机都有被抓概率，
后果包括没收、请家长、取消评优、学习减益数周；自律会有正向回报。

**经济**：不再每周固定掉钱。考试后父母按成绩给或扣零花钱；
向父母要零花钱不耗时间，但亲情 <100 每周 1 次、≥100 每周 2 次。
**经济不允许为负**，所有花钱统一走 `spendMoney()`。

## 三种打开方式

1. **双击即玩**：双击 `index.html`，不需要联网、不需要安装任何东西。
2. **一键启动**：Windows 用 `start-game.bat`，Mac 用 `start-game.command`。
3. **全校展示 / 局域网**：`start-server.bat`，同 WiFi 下手机电脑都能访问（需 Python）。
   起服务时改 `docs/*.md` 刷新即生效；双击打开则用打包好的 `js/00-docs.js`。

放到 GitHub Pages：`git init` → `git add .` → `git commit` → `git push`，
再到 Settings → Pages → Source 选 main 分支根目录。

附：给老师审核的单文件版 —— 运行 `node tools/make-single.js` 生成 `game.html`，
一个文件包含全部内容，微信、U 盘都能发。

## 存档与版本兼容

3 个本地存档槽，每周结算完自动存一次，中考与结局立刻落盘。
存档写在浏览器 `localStorage`，键名 `zhongkao_life_saves_v6`。

`js/18-save.js` 里有一张**逐级迁移表 `MIGRATIONS`**：旧档读进来会
从它自己的版本号一路升到 `SAVE_VER`，每级只补自己那一批新增字段
（幂等，不覆盖合法值）。以后改存档结构只要做两件事：

1. 在 `MIGRATIONS` 里加一级 `{目标版本: up函数}`
2. `SAVE_VER + 1`

`loadSaves()` / `resumeGame()` 都不用动。另外：

- 新档带 `__sum` 校验和；旧档没有就跳过校验，不误伤
- 来自**更新版本**的档只读不写，主菜单会提示「请升级游戏后再读取」，
  不会被旧版结构覆盖
- 读档时统一跑一次 `sanitizeState()`（`js/01-utils.js`），把周数、
  剩余时间、文具耐久、读书进度、对象型字段都钉在合法区间里
- 没有导出 / 导入存档文件的功能（目前不需要跨设备）

**关于英语模式**：界面上的切换按钮已移除，全中文。
`L("key")` 的调用点全部保留，将来接回英语不用改调用处。

## 性能红线（别加回来）

优化前：三种氛围特效叠加 27fps、弹窗打开 26fps、日志累积 1500 条 13fps。
现在全部 60fps。三条规矩：

- **不要给顶栏 / 弹窗加 `backdrop-filter: blur`**：`--panel` 本来就不透明，
  模糊的是被遮住的区域，纯浪费
- **氛围特效保持单个全屏层**（`css/05-mood.css`），别拆多个伪元素，
  更别用 `mix-blend-mode`
- **无限动画只动 `opacity` / `transform`**；日志 DOM 上限、
  `setHudHtml()` 写入去重、`say()` 滚动合并到下一帧，都别删

`node tools/check-content.js` 里的 `checkRenderPerf()` 会自动查这些。

## 学校特色

`js/02-config.js` 里填了校名、校训、立行文化四立、立行号与主题色清华紫。
学校专属事件在 `js/08-data-events-school.js`：立行号、校训墙、叠被子大赛、
宿舍熄灯后、内务检查、花灯社团研学、《聂耳》花灯剧、社团招新、竞赛选拔、
体育艺术文化节、家校团建、秋日林荫道、期末复誓等，单独存放，升级本体不会覆盖。

体艺节一年一个主题：初一**少年**、初二**行者**、初三**星辰大海**。

**关于图片**：学校目前没有官方校徽，游戏不使用校徽图标，只用校名与校训文字。
`usePhotos` 当前为 `false`，界面用九套主题自带的渐变底色，不会白屏。
想恢复把开关改回 `true`、图片放回 `assets/` 即可；恢复时背景应为校园实景的
扁平矢量插画风格艺术化重绘，不含真实人物、不出现校服与肖像。

## 技术说明

纯静态网页：HTML + CSS + 原生 JavaScript，无任何依赖、无构建步骤。
数据保存在浏览器 `localStorage`，不联网、不采集信息。
所有数值经过边界处理，不会出现 NaN。
系统开了「减少动态效果」时，全部动画与氛围呼吸自动停用。
